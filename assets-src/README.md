# 素材来源

- 0x72 Dungeon Tileset II v1.7 —— https://0x72.itch.io/dungeontileset-ii
- 许可：CC0（作者页面原文："You can use this tileset for whatever you like (CC-0)."）。压缩包内未附许可证文件，以作者页面为准。
- 这里保存原始素材，运行时使用的文件由开发过程复制/整理到 `public/assets/tiles/`。
- 素材坐标清单见 `0x72_DungeonTilesetII_v1.7/tile_list_v1.7`（格式：名称 x y 宽 高）。角色多为 16×28，高于 16×16 的格子，绘制时底边对齐格子底边。
